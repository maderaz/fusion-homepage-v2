## Code review

- Do a deep code review
- Look for:
  - security issues
  - hacks
  - dirty workarounds
  - not appreciate content
  - code that is unstable, can breake
  - non deterministic behaviour, race conditions
  - dead code, dead content - never displayed
- Act as frontend developer and security expert exper
- Spawn multiple agents for code review from diferent angles in team mode
- Code should be:
  - clean
  - well structured
  - well documented
  - self explanatory - minimal comments, verbose varnames
  - comments where code is complex and not obvious
