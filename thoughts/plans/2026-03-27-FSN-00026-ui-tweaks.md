# FSN-00026 UI Tweaks Implementation Plan

## Overview

Two UI adjustments to match the Figma design at https://fusionhome.figma.site/:

1. Show vault-overview.png on mobile in the transparency section
2. Put "Audited & security reviewed by" text on a separate line from the auditor logos

## Current State Analysis

### Transparency section (`src/components/transparency-features.astro`)

- **Line 14**: The vault-overview image wrapper uses `hidden lg:flex`, hiding the image on all screens below `lg` (1024px)
- On desktop it shows as a 50/50 layout: image left, features right
- The Figma design shows the image **above** the text content on mobile, visible at all breakpoints

### Security section (`src/components/security.astro`)

- **Lines 294-307**: "Audited & security reviewed by" text and logos are in a single `flex-wrap` row with `gap-8`
- The Figma design shows them as a `flex-col` with:
  - Text on its own line (centered)
  - Logos in a separate `flex-wrap` row below (centered)
  - `gap-4` (16px) between text and logos row
  - Text style: `text-[12px] font-medium`, Poppins font (already project default)

## What We're NOT Doing

- No content changes to the feature grid or stats
- No layout changes beyond these two specific areas
- No responsive breakpoint changes beyond showing the image on mobile

## Phase 1: Show vault-overview.png on mobile

### Changes Required

**File**: `src/components/transparency-features.astro`

Change the image wrapper (line 14) from:

```html
<div class="hidden lg:flex w-full lg:w-1/2 items-center justify-center"></div>
```

to:

```html
<div class="flex w-full lg:w-1/2 items-center justify-center"></div>
```

This removes `hidden lg:flex` and replaces with just `flex`, making the image visible at all breakpoints. On mobile it will appear above the features (due to `flex-col` on the parent at line 12), on desktop it stays as the left column.

### Success Criteria

#### Automated Verification

- [ ] Build passes: `npm run build`
- [ ] No type errors: `npx astro check`

#### Manual Verification

- [ ] vault-overview.png is visible on mobile (375px viewport)
- [ ] Image appears above the "Full Transparency" text on mobile
- [ ] Desktop layout unchanged (image left, features right)
- [ ] Image is responsive and properly sized on all breakpoints

## Phase 2: Separate "Audited & security reviewed by" from logos

### Changes Required

**File**: `src/components/security.astro`

Change lines 294-307 from:

```html
<div class="mt-8 flex flex-wrap items-center justify-center gap-8">
  <span class="text-[12px] font-medium text-muted-foreground">
    Audited & security reviewed by
  </span>
  {auditors.map((a) => (
  <img
    src="{a.logo}"
    alt="{a.name}"
    class="h-5 w-auto object-contain brightness-0 opacity-50 dark:invert"
  />
  ))}
</div>
```

to:

```html
<div class="mt-8 flex flex-col items-center justify-center gap-4">
  <span class="text-[12px] font-medium text-muted-foreground">
    Audited & security reviewed by
  </span>
  <div class="flex flex-wrap items-center justify-center gap-8">
    {auditors.map((a) => (
    <img
      src="{a.logo}"
      alt="{a.name}"
      class="h-5 w-auto object-contain brightness-0 opacity-50 dark:invert"
    />
    ))}
  </div>
</div>
```

Changes:

- Outer container: `flex-wrap` → `flex-col`, `gap-8` → `gap-4` (matches Figma's 16px gap)
- Logos wrapped in their own `flex-wrap` row with `gap-8`
- Text style stays `text-[12px] font-medium text-muted-foreground` (matches Figma exactly)

### Success Criteria

#### Automated Verification

- [ ] Build passes: `npm run build`
- [ ] No type errors: `npx astro check`

#### Manual Verification

- [ ] "Audited & security reviewed by" text appears on its own centered line
- [ ] Auditor logos appear on a separate line below the text
- [ ] Spacing between text and logos matches Figma (~16px)
- [ ] Layout looks correct on both mobile and desktop
- [ ] Dark mode styling still works correctly
