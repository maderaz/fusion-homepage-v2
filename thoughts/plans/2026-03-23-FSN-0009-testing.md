# Testing & Code Quality Implementation Plan

## Overview

Fill the remaining gaps in the Fusion website testing strategy: runtime console error/warning detection across all pages, dead code detection via `knip`, and meaningful unit tests for React components and utilities. All checks run in pre-push hooks and CI.

## Current State Analysis

The project already has solid testing infrastructure:

- **TypeScript checking**: `astro check` runs in build script
- **Build verification**: `astro build` in pre-push and CI
- **Unit tests**: Vitest configured with jsdom, but only 1 trivial smoke test (`src/app.test.tsx`)
- **Visual regression**: Playwright screenshots for 6 sections x 2 themes (`tests/visual/sections.spec.ts`)
- **CSP tests**: Playwright console + meta tag checks (`tests/visual/csp.spec.ts`)
- **Linting**: ESLint 9 flat config with TypeScript, React Hooks, and Astro plugins
- **Formatting**: Prettier via lint-staged on pre-commit
- **Pre-push**: runs `lint → test → build → test:visual` in sequence
- **CI**: `test-webapp.yml` reusable workflow runs the same suite on PRs and pushes

### Gaps:

| #   | Requirement                        | Status                                                  |
| --- | ---------------------------------- | ------------------------------------------------------- |
| 1   | No runtime console errors/warnings | Only CSP errors checked, not general JS errors/warnings |
| 2   | No unused exports / dead code      | No tooling in place                                     |
| 3   | Meaningful unit tests              | Only 1 smoke test that asserts `container` is truthy    |

## Desired End State

After this plan is complete:

1. A Playwright test navigates all 4 pages in both light and dark themes, capturing **any** `console.error` or `console.warn` messages, and fails if any are found
2. `knip` is installed and configured, detecting unused files, exports, dependencies, and types — integrated into pre-push and CI
3. Unit tests cover real component behavior: `cn()` utility, `useTheme()` hook, `CookieBannerIsland` consent flow, and `Nav` menu toggle + theme toggle
4. All checks run on pre-push (`npm run lint && npm test && npm run build && npm run test:visual`) and CI

### Verification:

```bash
# All must pass with zero errors:
npm run knip          # No unused exports/files/dependencies
npm test              # All unit tests pass
npm run build         # TypeScript + Astro build clean
npm run test:visual   # Visual regression + CSP + console error tests pass
npm run lint          # ESLint clean
```

## What We're NOT Doing

- Full unit test coverage for all components (that's fsn_0002-qa scope)
- Performance testing or Lighthouse CI
- Accessibility testing automation
- Cross-browser visual regression (staying with chromium only)
- Component-level Storybook stories
- Mobile viewport visual regression tests

## Implementation Approach

Work in 4 incremental phases. Each phase is independently verifiable and adds a new capability. Phases 1-3 are independent and can be implemented in any order. Phase 4 ties them together.

## Phase 1: Runtime Console Error/Warning E2E Tests

### Overview

Create a Playwright test that checks all 4 pages in both light and dark themes for any runtime `console.error` or `console.warn` messages. This goes beyond the existing CSP test by catching all JavaScript runtime issues.

### Changes Required:

#### 1. New test file

**File**: `tests/visual/console-errors.spec.ts` (new)

```typescript
import { test, expect } from "@playwright/test";

const pages = ["/", "/privacy-policy/", "/terms-of-use/", "/brand-guidelines/"];

const themes = ["light", "dark"] as const;

for (const path of pages) {
  for (const theme of themes) {
    test(`no console errors or warnings on ${path} (${theme} mode)`, async ({
      page,
    }) => {
      const issues: string[] = [];

      page.on("console", (msg) => {
        if (msg.type() === "error" || msg.type() === "warning") {
          issues.push(`[${msg.type()}] ${msg.text()}`);
        }
      });

      page.on("pageerror", (error) => {
        issues.push(`[pageerror] ${error.message}`);
      });

      await page.goto(path, { waitUntil: "networkidle" });

      // Set theme after load
      if (theme === "dark") {
        await page.evaluate(() =>
          document.documentElement.classList.add("dark"),
        );
      } else {
        await page.evaluate(() =>
          document.documentElement.classList.remove("dark"),
        );
      }

      // Wait for any theme-triggered re-renders
      await page.waitForTimeout(500);

      expect(issues).toEqual([]);
    });
  }
}
```

This creates 8 tests (4 pages x 2 themes). It captures:

- `console.error` — runtime JS errors logged to console
- `console.warn` — deprecation warnings, React warnings, etc.
- `pageerror` — uncaught exceptions (thrown errors not caught by any handler)

### Success Criteria:

#### Automated Verification:

- [ ] `npm run build` passes (test file must not break build)
- [ ] `npm run test:visual` passes — all 8 new tests green with zero console errors/warnings across all pages and themes

#### Manual Verification:

- [ ] Open browser DevTools on each page, confirm console is clean

## Phase 2: Dead Code Detection with Knip

### Overview

Install and configure `knip` to detect unused files, exports, dependencies, and types. Add as an npm script and integrate into the testing pipeline.

### Changes Required:

#### 1. Install knip

```bash
npm install --save-dev knip
```

#### 2. Create knip configuration

**File**: `knip.json` (new, at project root)

```json
{
  "$schema": "https://unpkg.com/knip/schema.json",
  "project": ["**/*.{js,mjs,cjs,ts,mts,cts,tsx,jsx,astro,css}"],
  "ignore": [
    "dist/**",
    ".astro/**",
    "public/**",
    "playwright-report/**",
    "test-results/**"
  ],
  "ignoreDependencies": [
    "@tailwindcss/vite",
    "tw-animate-css",
    "serve",
    "jsdom"
  ],
  "ignoreBinaries": ["npx"]
}
```

**Rationale for `ignoreDependencies`:**

- `@tailwindcss/vite` — referenced as a Vite plugin object in `astro.config.mjs`; knip's AST resolver may not trace it
- `tw-animate-css` — CSS-only package imported via `@import` in `.css` files
- `serve` — only used in Playwright's `webServer` command, not imported in source
- `jsdom` — referenced as a string in `vitest.config.ts` (`environment: "jsdom"`), not a direct import

#### 3. Add npm script

**File**: `package.json`
**Change**: Add `knip` script after `test:visual:update`:

```json
"knip": "knip"
```

#### 4. Run knip and fix findings

After initial setup, run `npm run knip` and address any real unused code it finds. If there are false positives beyond the `ignoreDependencies` list, add them to the config. If there is genuinely unused code, remove it.

**Likely findings to investigate:**

- `src/app/components/ui/theme-context.tsx` — This is an alternative `ThemeProvider`/`useTheme` implementation that appears to be unused (all components import from `src/components/use-theme.ts` instead). If confirmed unused, delete it.
- `src/app/components/cookie-banner.tsx` — May be unused if only `src/components/cookie-banner-island.tsx` is used in the Astro layout. If confirmed unused, delete it.
- Any unused exports within files that are otherwise used.

### Success Criteria:

#### Automated Verification:

- [ ] `npm run knip` exits with code 0 (no unused files, exports, or dependencies)
- [ ] `npm run build` still passes after removing any dead code

#### Manual Verification:

- [ ] Review knip output to confirm all findings are genuine (no false positives suppressed incorrectly)

#### 2. `useTheme()` hook tests

**File**: `src/components/use-theme.test.ts` (new)

```typescript
import { describe, it, expect, beforeEach } from "vitest";
import { renderHook, act } from "@testing-library/react";
import { useTheme } from "./use-theme";

describe("useTheme", () => {
  beforeEach(() => {
    document.documentElement.classList.remove("dark");
    localStorage.clear();
  });

  it("returns isDark=false when dark class is absent", () => {
    const { result } = renderHook(() => useTheme());
    expect(result.current.isDark).toBe(false);
    expect(result.current.theme).toBe("light");
  });

  it("returns isDark=true when dark class is present", () => {
    document.documentElement.classList.add("dark");
    const { result } = renderHook(() => useTheme());
    expect(result.current.isDark).toBe(true);
    expect(result.current.theme).toBe("dark");
  });

  it("toggleTheme switches from light to dark", () => {
    const { result } = renderHook(() => useTheme());
    act(() => result.current.toggleTheme());
    expect(result.current.isDark).toBe(true);
    expect(document.documentElement.classList.contains("dark")).toBe(true);
    expect(localStorage.getItem("fusion-theme")).toBe("dark");
  });

  it("toggleTheme switches from dark to light", () => {
    document.documentElement.classList.add("dark");
    const { result } = renderHook(() => useTheme());
    act(() => result.current.toggleTheme());
    expect(result.current.isDark).toBe(false);
    expect(document.documentElement.classList.contains("dark")).toBe(false);
    expect(localStorage.getItem("fusion-theme")).toBe("light");
  });
});
```

#### 3. `CookieBannerIsland` component tests

**File**: `src/components/cookie-banner-island.test.tsx` (new)

```typescript
import { describe, it, expect, beforeEach } from "vitest";
import { render, screen, fireEvent } from "@testing-library/react";
import CookieBannerIsland from "./cookie-banner-island";

describe("CookieBannerIsland", () => {
  beforeEach(() => {
    sessionStorage.clear();
  });

  it("shows banner when no consent stored", () => {
    render(<CookieBannerIsland />);
    expect(screen.getByText("Cookie Preferences")).toBeInTheDocument();
  });

  it("hides banner when consent already stored", () => {
    sessionStorage.setItem("cookie_consent", "accepted");
    render(<CookieBannerIsland />);
    expect(screen.queryByText("Cookie Preferences")).not.toBeInTheDocument();
  });

  it("accept button stores consent and hides banner", () => {
    render(<CookieBannerIsland />);
    fireEvent.click(screen.getByText("Accept"));
    expect(sessionStorage.getItem("cookie_consent")).toBe("accepted");
    expect(screen.queryByText("Cookie Preferences")).not.toBeInTheDocument();
  });

  it("decline button stores decline and hides banner", () => {
    render(<CookieBannerIsland />);
    fireEvent.click(screen.getByText("Decline"));
    expect(sessionStorage.getItem("cookie_consent")).toBe("declined");
    expect(screen.queryByText("Cookie Preferences")).not.toBeInTheDocument();
  });

  it("X button declines and hides banner", () => {
    render(<CookieBannerIsland />);
    // The X button is a sibling of the "Cookie Preferences" heading
    const closeButtons = screen.getAllByRole("button");
    const xButton = closeButtons.find(
      (btn) => btn.textContent === "" || btn.querySelector("svg"),
    );
    if (xButton) fireEvent.click(xButton);
    expect(sessionStorage.getItem("cookie_consent")).toBe("declined");
    expect(screen.queryByText("Cookie Preferences")).not.toBeInTheDocument();
  });

  it("reopens when open-cookie-settings event is dispatched", () => {
    sessionStorage.setItem("cookie_consent", "accepted");
    render(<CookieBannerIsland />);
    expect(screen.queryByText("Cookie Preferences")).not.toBeInTheDocument();

    // Dispatch the custom event
    window.dispatchEvent(new Event("open-cookie-settings"));
    expect(screen.getByText("Cookie Preferences")).toBeInTheDocument();
  });
});
```

import { render, screen, fireEvent } from "@testing-library/react";

describe("Nav", () => {

      expect(document.documentElement.classList.contains("dark")).toBe(true);
    }
  });
